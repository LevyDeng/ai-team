# Project instructions

- Simplified Chinese is the default language for every user-facing interface in AI 小队 (ai-team), including navigation, menus, buttons, labels, accessibility text, confirmations, empty states, and application-generated errors. Check each affected page and interaction for English-only UI before finishing a change.
- Preserve product names, model identifiers, commands, file paths, provider output, and user-authored content in their original form. When surfacing a raw diagnostic, present the actionable explanation in Simplified Chinese.
- Keep source comments, internal identifiers, developer logs, and test fixtures in English unless explicitly requested otherwise.
- Keep promotional video production files local. Put new temporary media work under the repository-root `.tmp/` directory.
