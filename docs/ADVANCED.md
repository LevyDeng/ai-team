# 进阶配置与排障

## 托管 VPS 安装选项

`Setup-RelayDesk.ps1` 用于准备 Windows 端依赖和 SSH 连接、配置 Ubuntu VPS 上的托管运行环境，以及生成快捷方式。安装前可从项目根目录运行 `setup-relay-desk.cmd -Plan` 查看步骤。

| 选项 | 用途 |
| --- | --- |
| `-Server`、`-Port` | VPS 地址和 SSH 端口 |
| `-AdminUser`、`-AppUser` | 安装时的管理账号和日常运行账号 |
| `-KeyPath` | 当前 Windows 用户可访问的 SSH 私钥路径 |
| `-ExistingServer` | 跳过管理员部署步骤，使用已准备好的服务器和运行用户 |
| `-SkipDependencies`、`-SkipLogin` | 跳过本机依赖安装或首次登录步骤 |
| `-NoShortcut`、`-NoLaunch` | 跳过创建快捷方式或安装后启动 |

如果手动维护托管安装，请以仓库根目录的 `.env.example` 为模板，并为自己的部署创建 `.env`。`New-Secret.ps1` 可生成 Windows-MCP 连接所需的密钥。前往另一台服务器前先核对本机配置，保留现有部署的账号和密钥。

## 常见问题

- **首次启动失败**：在 PowerShell 里运行 `node --version` 和 `npm --version`，再从项目目录运行 `.\relay-desk.cmd` 查看启动输出。首次安装需要能够下载项目依赖。
- **提示缺少工作目录**：打开当前项目的设置，检查提示所列角色的运行位置，并为该位置添加目录。VPS 上的目录由该 SSH 用户访问。
- **SSH 连不上**：先用系统 SSH 验证主机、端口、用户名和私钥路径。首次连接时比对主机指纹。如果位置配置了代理，检查该代理能否连到服务器。
- **有连接，但 Agent 没回复**：确认所选运行位置上已安装并登录相应 CLI，角色设置使用账号实际支持的模型。在消息下点「任务输出」查看错误。
- **重启提示仍有任务**：从左下角「工作台」检查任务，等待由工作台管理的活动任务和终端结束后重试。符合条件的本机后台任务可以继续运行。
- **需要保留账号和对话配置**：将 `.runtime/`、真实 `.env` 及所需私钥分别私密备份。重新安装前确认新环境使用哪些配置，避免让其他人拿到备份数据。

日常操作见[工作台使用说明](Relay-Desk-Workbench.md)。
