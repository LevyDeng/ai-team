准备就绪

  

  
添加项目
服务器上的文件夹。如果尚不存在，开始对话时会自动创建。
仅用于打开本地路径，不会上传目录或改变远端工作目录。

  
项目目录
第一项是终端和文件浏览器的默认目录。聊天里的相对链接使用第一项 Windows 目录。

  
删除项目
项目及其对话会从本机列表移除。服务器上的项目文件、历史记录保留；本机保留项目元数据备份。

  
重命名对话

  
连接服务器
连接信息和 MCP 密钥从项目的 .env 文件读取。
口令仅用于本次连接，不会保存。

  
连接配置
保存后立即应用，无需重开 App。更改 SSH 连接信息会自动重连，远端会话保留。
会话上限由所有项目、Claude 和 Codex 共用。降低上限不会自动结束已有会话；新会话仍需通过内存检查。

  
释放一个会话名额
结束会中断该会话当前任务，历史记录保留。腾出位置后会自动继续连接目标对话。

  
本机发送记录
提交到远端终端后即清空输入框，文字备份保留。“远端已确认接收”表示另已核对到会话记录；两种状态均不代表任务完成。恢复只填入文字，不会自动发送；附件请核对或重新添加。
